# SOL E MANGA — visualizador 3D

Visualizador 3D do carrinho rebocável **SOL E MANGA — Manga Verde Temperada**, elaborado a partir das pranchas de anteprojeto arquitetônico.

## Abrir

https://karlosqwer.github.io/karlos-portfolio/sol-e-manga/

O arquivo `index.html` é a página publicada no GitHub Pages e incorpora o modelo tridimensional para carregar sem buscar outro arquivo GLB. O arquivo `sol_e_manga_carrinho.glb` também está disponibilizado separadamente para download e abertura no Blender. `visualizador.js` é uma cópia do código JavaScript para consulta e manutenção.

## Atenção

Modelo ilustrativo, não executivo. Antes de fabricar, validar as medidas e equipamentos com os arquitetos, serralheiro e engenheiro responsáveis. As pranchas marcam as dimensões da máquina de tirinhas como provisórias e exigem dimensionamento do chassi, engate, eixo e sapatas por engenheiro.
